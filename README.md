# Kart Neck Trainer

Web app per allenare il collo per il go-kart con la macchina **Sintesi by Akuis** (due colonne a cavi motorizzati).

- **Simulatore**: funziona su qualsiasi browser, anche iPad.
- **Collegamento Bluetooth alla macchina**: Chrome su Android, oppure l'app **Bluefy** su iPad/iPhone.

App: https://franxakathegoat-boop.github.io/kart-trainer/

## Sicurezza
Prototipo non ufficiale. Usare sempre carichi bassi per le prove e tenere il pulsante rosso di emergenza della macchina a portata di mano.
